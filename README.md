# Распознавание типов потоков и магнито-плазменных структур в солнечном ветре

**Куратор:** Блуменау Марк Ильич

**Состав группы:** - Мезенцева Мария Евгеньевна - Зуев Гордей Андреевич

## 1. Тема проекта

**Распознавание основных типов потоков и магнито-плазменных структур в солнечном ветре по данным космических аппаратов.**

Проект посвящён автоматическому распознаванию структур солнечного ветра по временным рядам измерений магнитного поля и параметров плазмы, а также временной локализации обнаруженных событий.

## 2. Цель работы

Разработать модель, которая по истории измерений магнитного поля и параметров плазмы определяет тип структуры солнечного ветра и оценивает время её начала.

В постановке предусмотрены три взаимосвязанные задачи:

1.  **Классификация типа структуры**

    -   `background` --- фоновый солнечный ветер;
    -   `SIR/CIR` --- области взаимодействия потоков;
    -   `CME/ICME` --- события, связанные с корональными выбросами массы и их межпланетными проявлениями.

2.  **Временная локализация**\
    Оценка лага между концом входного окна и каталожным временем начала события.

3.  **Уточнение типа события при наличии соответствующей разметки**\
    Использование отдельных классификационных голов внутри родительского класса.


## 3. Используемые данные

В качестве входных признаков рассматриваются измерения магнитного поля и параметров плазмы:

  -----------------------------------------------------------------------
  Группа признаков                    Параметры
  ----------------------------------- -----------------------------------
  **Магнитное поле**                  модуль `B`, компоненты `Bx`, `By`, `Bz`

  **Скорость плазмы**                 модуль `V`, компоненты `Vx`, `Vy`, `Vz`

  **Параметры протонов**              плотность `Np`, тепловая скорость `W`, вычисляемая температура `Tp`

  **Временные данные**                время измерения

  **Разметка событий**                `background`, `SIR_CIR`, `CME_ICME`

  **Метаданные**                      идентификатор события, источник разметки, уточняющая метка при её наличии

  **Производные представления**       тренд и остаток, FFT/Welch, STFT, CWT, вейвлет-разложения, компоненты SSA, доля доступных измерений
  -----------------------------------------------------------------------

## 4. Бейзлайн

Базовая архитектура строится на **Transformer** и включает:

-   кодирование исходных временных рядов и их производных представлений;
-   обучаемый выбор семейств представлений;
-   общую Transformer-часть для извлечения временных зависимостей;
-   отдельные queries/головы для классификации структуры и временной локализации события.

Бейзлайн должен позволить отдельно оценить вклад различных представлений сигнала и сравнить фиксированный набор представлений с обучаемым выбором.

## 5. План работы

1.  **Подготовка данных**
    -   проанализировать доступные датасеты и источники разметки;
    -   выбрать набор физических параметров;
    -   синхронизировать временные ряды и обработать пропуски;
    -   сформировать обучающие окна и разбиение данных.
2.  **Построение воспроизводимого бейзлайна**
    -   реализовать классификацию `background` / `SIR/CIR` / `CME/ICME`;
    -   добавить временную локализацию начала события;
    -   оценить качество классификации, задержку обнаружения и ложные срабатывания;
    -   проверить целевой сценарий обнаружения события не позднее чем через 3 часа после его начала.
3.  **Исследование представлений сигнала**
    -   сравнить исходный временной ряд с трендовыми, спектральными, вейвлет- и другими разложениями;
    -   провести ablation study для оценки вклада отдельных представлений;
    -   исследовать обучаемый выбор представлений для каждого входного окна.
4.  **Развитие архитектуры**
    -   масштабировать подход на различные типы событий и уточняющие классы при наличии разметки;
    -   исследовать иерархическую классификацию;
    -   исследовать decoupled queries для разделения задач классификации и локализации;
    -   сравнить предложенные модификации с базовой архитектурой.
5.  **Итоговая оценка**
    -   провести оценку на непрерывных временных рядах;
    -   проанализировать задержку детектирования и ложные тревоги;
    -   определить, какие физические параметры и представления сигнала наиболее информативны для разных классов событий.

## 6. Ожидаемый результат

Результатом проекта должна стать модель для автоматического распознавания и временной локализации основных структур солнечного ветра, а также экспериментальное сравнение различных представлений временных рядов.
